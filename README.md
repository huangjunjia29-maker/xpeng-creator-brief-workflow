# 小鹏海外创作者 Brief 工作流

将总部海外传播资料及 KOC Creatives Package 转化为中英文 Creator Brief，并从用户和老板修改中持续改进写法。

## 仓库内容

- [写作 skill](skills/xpeng-creator-brief/SKILL.md)：选题、信息拆解、二创角度、Hook、中英文一致性及事实边界。
- [老板修改学习](skills/xpeng-creator-brief/references/editor-learning.md)：2026年9月15日香港兆瓦闪充站案例的修改依据。
- [Brief 内容模板](templates/creator-brief.md)：四大栏目及中英文顺序。

仓库保存可复用工作流和经过整理的学习记录。原始传播资料、个人路径、每日 Word 产物及临时文件不纳入版本管理。案例记录包含业务写作经验，建议使用私有仓库。

## 日常流程

1. 提供当天输入文档，以及需要遵循的 Word 标准格式。完整读取新闻正文、KOC素材包、历史合作和全球化进展。
2. 提炼约三个不同层面的事实支点，逐一写成“事实 = 传播意义”。相同受众、相同利益点的内容合并。
3. 为各支点构思有反差的品牌观点，给出用户洞察、二创叙事、建议素材和拍法，以及通常三条英文 Hook。
4. 先写完整中文版，再写完整英文版；同步检查信息拆解、洞察、角度和Hook，保持事实一致、表达本土化。
5. 使用用户 Word 模板制作文件并核对参数、时间、素材和格式；可用时渲染检查每页，无法预览时明确说明。
6. 收到修改版后，与最近交付版比较，提炼可迁移规则并更新 skill。将新事实主张与表达偏好区分。

## 使用方式

在可读取本仓库的任务中，直接指定 `skills/xpeng-creator-brief/SKILL.md` 并提供当天资料。例如：

> 按仓库中的 xpeng-creator-brief skill，将附件总部资料制作成中英文 Creator Brief。沿用我提供的 Word 标准格式，完整考虑 KOC Creatives Package，让三个角度有明显区别。

也可以将 `skills/xpeng-creator-brief` 文件夹安装到个人技能目录中。仓库内的 Markdown 模板负责内容结构；视觉排版以实际提供的 Word 参考文件为准。

## 核心写作原则

- 从功能利益继续挖掘品牌观点；地点、数字、合作方和开放立场应共同构成故事。
- 角度可以覆盖用户体验、工程能力、产业合作、国际认知和全球服务，不全部围绕车主便利。
- Hook要有具体事件和反差，避免整组通用抱怨；长句区分短开头与后续补充。
- 保留有力度的创意，具体性能、比较、排名及现场状况必须有依据。
- 接入不等于自建，合作计划不等于已完成，系统峰值不等于每车功率。

## 维护

编辑仓库中的 skill 和学习记录后，再同步到个人安装目录。不要直接运行旧事件专用脚本生成新内容；每次输入的事实、日期和素材都需要重新读取。

本仓库是由创作者运营发起、AI协助执行的工作流程，并未配置定时抓取、自动发布或 GitHub Actions。
