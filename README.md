# 小鹏海外创作者 Brief 工作流

将总部海外传播资料及 KOC Creatives Package 转化为中英文 Creator Brief，并从用户和老板修改中持续改进写法。

## 仓库内容

- [写作 skill](skills/xpeng-creator-brief/SKILL.md)：选题、信息拆解、二创角度、Hook、中英文一致性及事实边界。
- [老板修改学习](skills/xpeng-creator-brief/references/editor-learning.md)：2026年9月15日香港兆瓦闪充站案例的修改依据。
- [选择与素材迭代学习](skills/xpeng-creator-brief/references/selection-and-media-learning.md)：可变角度数量、原话保留、编号映射与补充视频改稿。
- [本地价值与角度合并学习](skills/xpeng-creator-brief/references/local-value-and-angle-merging.md)：欧洲购买认知、具体价值表达，以及按用户要求优先合并国内方向、删除重复角度。
- [近期题材与证据学习](skills/xpeng-creator-brief/references/recent-topics-and-evidence.md)：Robotaxi竞品参照、GX中东实测和USCALE推荐排名案例，区分用户选择与编辑判断。
- [Brief 内容模板](templates/creator-brief.md)：四大栏目及中英文顺序。

仓库保存可复用工作流和经过整理的学习记录。原始传播资料、个人路径、每日 Word 产物及临时文件不纳入版本管理。案例记录包含业务写作经验，建议使用私有仓库。

## 日常流程

1. 提供当天输入文档，以及需要遵循的 Word 标准格式。完整读取新闻正文、KOC素材包、历史合作和全球化进展。
2. 确认当次传播事件，提炼不同层面的“事实 = 传播意义”。有合适延展话题时，在原点信息中显式区分重点和延展；没有时正常拆解事件本身，不强凑背景。
3. 先给通常6—8个编号候选角度，每项简述观点、洞察、资料支点、拍法及一句英文Hook；标明相近或替代选项。数量以素材为准，不强凑。
4. 等用户选择，通常推荐三个，最终数量以用户为准；四个也完整生成。可推荐组合但不自动代选，用户明确委托代选或直接生成时执行该次授权。
5. 按选定角度写完整中文版，再写完整英文版；原点信息保留总部完整原文，从信息点拆解起保持简洁。原则上一个入选角度对应一个信息点，每个角度通常三条英文Hook。有延展方向则从主事件引入，没有则正常写事件本身。
6. 使用用户 Word 模板制作文件并核对参数、时间、素材和格式；可用时渲染检查每页，无法预览时明确说明。
7. 收到修改版后，与最近交付版比较，提炼可迁移规则并更新 skill。将新事实主张与表达偏好区分。
8. 用户替换角度时，通过原候选与成稿编号映射定位，同步修改中英文相关栏目。收到补充视频先核看，再把新场景与主事件正确衔接。

## 使用方式

在可读取本仓库的任务中，直接指定 `skills/xpeng-creator-brief/SKILL.md` 并提供当天资料。例如：

> 按仓库中的 xpeng-creator-brief skill，先根据附件总部资料和KOC素材包提供候选创作者角度，我选定后再生成中英文Creator Brief和Word，角度数量按我的选择。有合适延展话题时标明主次；没有时正常写事件本身的不同角度。

也可以将 `skills/xpeng-creator-brief` 文件夹安装到个人技能目录中。仓库内的 Markdown 模板负责内容结构；视觉排版以实际提供的 Word 参考文件为准。

## 核心写作原则

- 原点信息中英文均保留总部完整原文和必要背景；其余内容默认“一事一句”，每个角度用一小段观点加一小段拍法。
- 中英文的角度数量、逻辑、证据和事实边界一致；英文自然转写，不要求逐字翻译。
- 重复限定集中写入注意事项；删除限定会造成误解时，将限定保留在对应主张旁。活动日、总部发布时间和Brief制作日期分别处理。
- 从功能利益继续挖掘品牌观点；地点、数字、合作方和开放立场应共同构成故事。
- 角度可以覆盖用户体验、工程能力、产业合作、国际认知和全球服务，不全部围绕车主便利。
- 从本地需求、熟悉车型和实际体验解释具体价值；价格、展台热度及本地生产本身不足以回答消费者为什么在意。车型参照与经过核实的比较结论分开。
- 不同角度服务同一个事件；仅在确有延展话题时标明重点与延展关系，不强行套用主次分类。
- Hook要有具体事件和反差，避免整组通用抱怨；长句区分短开头与后续补充。
- 保留有力度的创意，具体性能、比较、排名及现场状况必须有依据。
- 保留用户明确指定的原话与称呼；相近角度被同时选中时区分重点，不擅自合并。
- 用户明确要求国内方向优先、合并并去重时，按观点、证据和拍法判断重叠，执行指定顺序并删除实质重复项，同步中英文及编号；不将单次排序变成固定模板。
- 补充素材先核看，区分主事件、历史素材和另一个场景；图片或视频文件名不等于已看过内容。
- 接入不等于自建，合作计划不等于已完成，系统峰值不等于每车功率。
- 只把稳定、可跨事件复用的反馈写成工作流规则；单次编辑选择保留为案例。

## 维护

编辑仓库中的 skill 和学习记录后，再同步到个人安装目录。不要直接运行旧事件专用脚本生成新内容；每次输入的事实、日期和素材都需要重新读取。

本仓库是由创作者运营发起、AI协助执行的工作流程，并未配置定时抓取、自动发布或 GitHub Actions。
