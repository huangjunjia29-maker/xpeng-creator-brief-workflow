# 小鹏海外创作者 Brief

服务对象是小鹏海外创作者运营；输出面向海外创作者，目标是提升二创内容的观点、吸引力与可执行性。使用本土社会公约数痛点 × 情绪共鸣 × 品牌连接。品牌连接可以是产品帮助、技术能力、开放立场或产业角色，不必全部落到车主省时省心。

## 先选角度再生成

- 默认分两阶段：先提供候选角度，用户选定后，再制作完整中英文Brief和Word。通常推荐三个，最终数量以用户选择为准；选四个就完整制作四个，不自行删减。收到“开始写今天的”等请求时，先进行候选阶段；用户明确要求直接生成、已经选好角度或委托补选时，完成已授权工作，不重复询问。单次委托代选不变成以后自动代选的规则。
- 候选阶段通常提供6—8个有依据的方向，数量随素材丰富度调整，不为凑数换词重复。用稳定编号方便选择，每项包含观点标题、核心反差或受众洞察、原始资料支点、拍法及一句代表性英文Hook。可用紧凑表格呈现，尚不展开全套中英文正文。
- 明确此次重点事件、是否包含延展方向。可以推荐三个互补选项并说明理由，但推荐不等于用户选择；需等待用户选定，不自行超时默认生成。允许用户组合、修改或要求更多候选。
- 标明候选间的同源或替代关系，避免将技术解释和同一技术的用户利益误作完全独立事件。每个候选都必须回到本次事件。
- 用户选定后，根据最终角度同步编写原点信息、信息点拆解、洞察、叙事、每角度通常三条英文Hook和平台注意事项。原则上一个入选角度对应一个清晰的信息点；两个角度确实共用同一事实基础时可以合并信息点。最终角度可连续重编号，保留原候选到成稿编号的映射用于核对；未选角度不塞入成稿。相近方向被用户同时选中时，区分受众、观点或事实支点，不擅自合并。

## 阅读和选择信息

- 阅读完整输入，包括后半部分 KOC Creatives Package、历史合作、全球化进展、配图和发布要求。先确认本次重点事件，再判断配套资料是否适合提取延展话题；不要将历史合作或全球背景写成与当天事件并列的传播任务。
- 延展话题是可选项。没有合适延展内容时，正常围绕事件本身写不同角度，不强凑背景，不固定套用“一个重点＋两个延展”。事件内的不同角度也不必人为划成主次。
- 候选阶段探索不同事实支点和表达路径，成稿围绕用户选定的全部角度组织。用“对谁说、改变什么看法、由什么证据支撑”检查角度差异，同时检查它们是否仍服务于同一重点事件。等待、找桩、跨品牌使用若都在讲便利，应归为同一角度。
- 可从用户体验、技术与工程、产业合作、国际竞争与认知、全球化服务等不同层面选取；不强制每次都填同一套分类。
- 2026-09-15老板修改的具体证据见 [老板修改学习](references/editor-learning.md)。需要判断语气、角度深度或学习新修改时阅读；不把历史示例当成新事件的事实来源。

## 从事实写成传播观点

- 信息点拆解沿用“官方事实 = 值得传播的意义：具体展开”。意义要回答观众为何意外、会争论什么，以及小鹏在其中呈现了什么能力或立场。
- 优先寻找材料中的强反差，例如“小空间与大功率”“稀缺位置与开放共享”“油电对立印象与实际合作”。把矛盾、品牌行动和认知变化连成一个故事。
- 地点、数字、合作方、受益者要在故事里起作用。香港可以形成高密度城市的空间约束，小鹏自研技术可以成为回应，跨品牌开放可以形成品牌立场。不能只是罗列参数后泛称方便。
- 角度标题可以鲜明、有判断、有讨论性。根据实际主题选择技术自信、意外、重新评价、认同、释然等情绪，不只使用泛化的焦虑、自嘲。
- 关于国家、行业或竞品的认知反差是可选创作方向，不默认每个市场都要讲“西方傲慢”，也不把它当成已验证的人群特征。

## 输出结构和表达

先完整中文版，再完整英文版。以用户提供的标准格式或最新明确指定的参考版式为准。

- 原点信息 / Key briefing fact保留总部资料中的完整事件原文和必要背景，不为追求简洁而压缩或改写核心表述。从信息点拆解开始，正文默认“一事一句”，删除同义复述；每个角度通常用一小段讲清观点、一小段讲清拍法。用户要求标题和Hook不变时，只锁定这两类文字，角度正文与拍法仍应按反馈优化。
- 注意事项合并同类边界，优先保留会影响发布真实性、合规口径或执行的内容。平台建议只有确有差异时分别写；差异很小时可合并成一段简短说明。

1. 原点信息 / Key briefing fact：写清本次事件及核心事实。确有延展话题时，显式区分“重点话题 / Primary focus”和“延展话题 / Supporting context”，注明背景如何解释本次事件；没有时不添加空延展栏目。历史事件标年份，新计划和已实现进展分开。
2. 信息点拆解 / Core message to communicate：覆盖全部选定角度的传播支点，写出事实的意义和品牌观点，数量随选定方向调整。有延展支点时标注其性质及与当次事件的关系；没有时正常拆解事件自身的信息。
3. 二创切入角度 / Content angles for inspiration：用户洞察；各角度的标题、核心叙事、素材、拍法及英文Hook；必带与建议话题词。含延展话题时标明重点方向与延展方向；仅有事件自身角度时正常编号，不硬将Angle 2、3标为延展。不自行增加全部角度都要拍的要求。
4. 注意事项 / Attention：事实表达和素材使用边界，以及 TikTok、INS、X、FB 的适用建议。区分总部硬要求与创意建议。

- 每角度通常提供三条英文 Hook。让至少一条在开头直接带出品牌、具体事件或有证据的反差，不要整组都换成适用于任何品牌的生活抱怨。
- 延展角度也从重点事件引入，再转到历史合作、产业或全球背景，并解释其对本次事件的意义。主事件应出现在开头文案或首屏画面中；不要直到结尾才补提。Hook、配图建议及中英文都应遵循这一关系。
- 香港案例：Angle 1聚焦香港兆瓦闪充站；Angle 2由香港新站引出2025年bp充电合作，讨论更广的补能合作背景；Angle 3由香港新站引出全球网络服务进展。叙事关联不等于项目因果关系，不能暗示bp参与香港站建设。
- 区分真正适合前3秒的短开头与需要随后补充的完整句子；长文案不能仅贴“3秒Hook”标签。可以给“短Hook＋后续一句”。
- 英文是本土化创作指导，可采用 gatekeep 等自然社媒表达和观点式标题，不逐字翻译中文。力度来自具体故事，不靠堆叠夸张词。
- 拍法为观点服务：关键镜头、对比方式、节奏和结尾讨论点足够，不机械塞入创作者分类、相同POV和通用问句。
- 必要限定优先归入注意事项，创意段落保持清楚有力；影响一句话真实性的限定必须随该主张出现，如“系统峰值”和“网络接入”。
- 同步检查中文信息拆解、洞察、Angle、Hook与对应英文六个位置，避免只更新角度却遗留旧逻辑。改为技术开放的角度后，情绪也要随之调整。
- 中文与英文的角度数量、逻辑、证据和事实边界必须一致；英文可以自然改写，不必逐字翻译。

## 事实与创意的边界

保留用户和老板的创意力度，同时将新加入的可验证陈述与原始事实区分。老板修改是表达偏好的证据，不自动构成性能测试或市场调查的证据。

- 地价排名、当地基建状况、特定竞品车主实际到场、排队和具体充满时间需要相应来源。未提供时，保留可支持的强反差，改为可验证陈述或真实问题。
- 例如可说“一座位于高密度香港城区、向各品牌开放的兆瓦闪充站”，不自动写成“世界最贵地块、所有车10分钟充满、特斯拉车主已排队”。不要用问号包装本不存在的现场事实。
- 场站系统峰值不等于每车功率；四个车位不等于四个兆瓦位；储能容量与功率分清。开放服务不等于任意车型和接口无条件兼容。
- 网络“接入”不等于自建，合作MOU不等于全部计划已经完成，全球服务网络不等于全球落地同款兆瓦站。
- 不从历史bp合作推断bp建设本次香港站；不把历史图片当成新事件现场。

## 文件制作与学习更新

- 用户强调保留原话、指定称呼或标题时，保留其创意力度，不擅自改成泛化表达；英文自然适配。具体事实仍需依据，限定尽量放入注意事项，不让创意正文变成解释清单。
- 用户说“把4改成……”时，结合候选与成稿编号映射定位；编号已重排时简短说明对应位置。同步修改中英文原点信息、信息拆解、洞察、叙事、拍法、Hook及相关平台建议，清理旧逻辑，保留其他选定角度。证据与近期适用案例见[选择与素材迭代学习](references/selection-and-media-learning.md)。
- 新增图片或视频先核看再改写。确认主体、动作、场景和前后过程；只有文件名或素材包条目时，不声称已观看。抽帧核看应覆盖全片并检查关键帧；仅核看画面不等于已听取音频。无法核看时说明缺口，不能臆造镜头或台词。
- 补充视频、历史展厅与主事件素材区分标识。可以从主事件引入补充素材，不推断同一时间地点、人物身份、动物归属或因果。排期按当次等级及首发时点计算，区分活动、总部发布、Brief制作日期；区域同步要求与创作者合作安排分别写明。

制作Word时使用可用的文档技能与实际用户模板，按最新内容更新，不固定沿用旧事件和旧脚本。可用时渲染并检查每页；渲染失败应说明原因和未核验范围，不能把XML检查当成页面视觉检查。

用户交来修改版时，与最近实际交付版本对比正文、表格和批注，忽略纯空格、引号、编号造成的噪音。先指出主要变化与保留内容，再归纳可迁移的取舍。未改部分不等于全面认可。将新证据增量写入本skill或引用文件；学习请求本身不要求擅自重写用户文件。

只将用户或老板反复确认、能够跨事件复用的反馈沉淀为通用规则；单次题材、措辞和编辑选择保留为案例，不自动升级为以后都要遵守的要求。
